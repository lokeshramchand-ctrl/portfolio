# Lokesh Ram Chand — Portfolio

A scroll-driven portfolio built as a single narrative: watching a building go up as the
story of becoming a software engineer. Next.js 16 (App Router), TypeScript, Tailwind CSS
4, GSAP + ScrollTrigger, Lenis.

See `CLAUDE.md` for architecture, conventions, and design rules, and `docs/` for the
design system, content source of truth, animation spec, and decision log.

## Development

```bash
npm install
npm run dev      # start dev server
npm run build    # type-check + production build
npm run lint     # eslint
```
